# For Maica ♥

A romantic envelope website: tap the envelope, see the photos and message, with music playing.

## Files
- `index.html` – the website
- `photo1.jpg` … `photo4.jpg` – the photos
- `song.mp3` – the background music

## Put it online with GitHub Pages
1. Create a new repository on GitHub (e.g. `for-maica`).
2. Upload all the files in this folder to the repository root (Add file → Upload files).
3. Go to Settings → Pages.
4. Under "Build and deployment", choose "Deploy from a branch", pick `main` and `/ (root)`, then Save.
5. After a minute your site is live at `https://YOUR-USERNAME.github.io/for-maica/`

Note: the repository must be public for free GitHub Pages.
